# Asset Logistics System

A production-minded Firefly workflow for generating high-volume, brand-controlled asset sets.  
**Tone:** Beachpunk Gigadream — treat Firefly as logistics infrastructure, not a novelty generator.

## Core Pattern

### 1. Master Lock
Establish a single approved base asset.  
- Exact product geometry locked.  
- Brand colors and lighting direction fixed.  
- Style reference images saved.

### 2. Generative Fill / Expand with Constraints
Build lifestyle environments around the locked product.  
- Keep product geometry untouched.  
- Prompt language: cinematic continuity, film grain, specific lighting (e.g., “matching golden hour, Kodak Ektar, light leaks, hyper-detailed sand and metal”).  
- Use reference images for style lock.

### 3. Style-Matched Variant Batch
From one master, generate channel-specific variants (social, retail, print, motion stills).  
- Shared style seed / reference.  
- Consistent prompt core with channel-specific framing.

### 4. Consistency Pass
Manual or scripted check for:  
- Color drift  
- Geometry integrity  
- Lighting continuity  
- Brand lock

## Outcome Framing
- 3× more channel-ready variants from a single master  
- ~45% faster turnaround  
- Revision rounds reduced from 4 to ~1.5

This system moves Firefly from experimental tool to repeatable asset logistics.
