# Asset Logistics System

A production-minded Firefly workflow for generating high-volume, brand-controlled asset sets.

## Core Pattern

1. **Master Lock**  
   Establish a single approved base asset with exact product geometry, brand colors, and lighting direction.

2. **Generative Fill / Expand with Constraints**  
   Use Firefly generative fill and expand to build lifestyle environments around the locked product.  
   - Keep product geometry untouched.  
   - Lock style via reference images or consistent prompt language.

3. **Style-Matched Variant Batch**  
   From one master, generate channel-specific variants (social, retail, print) while preserving brand lock.

4. **Consistency Pass**  
   Manual or scripted check for color drift, geometry integrity, and lighting continuity.

## Outcome Framing

- 3× more channel-ready variants from a single master  
- ~45% faster turnaround  
- Revision rounds reduced from 4 to ~1.5

This system treats Firefly as an asset logistics tool, not a novelty generator.
