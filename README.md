# firefly-lab

Experimental Adobe Firefly workflows, shortcuts, and demos.  
**Tone:** Beachpunk Gigadream — high-complexity generative systems, cinematic asset logistics, Diamond Riot energy.

This is not a tutorial repo. These are production-minded patterns, power-user shortcuts, and novel uses for Firefly that treat generative tools as part of a larger creative operating system.

## Structure

- `/workflows` — documented, repeatable Firefly pipelines
- `/shortcuts` — keyboard and one-click systems for Firefly + Creative Cloud
- `/demos` — interactive or visual demonstrations
- `/hybrid` — crossovers with ComfyUI, Unreal, ElevenLabs, and other tools

## Flagship Pieces

### 1. Asset Logistics System
High-volume, brand-controlled generation with consistency checks and multi-channel export logic.

### 2. Cinematic Shortcut Pack
Power-user patterns for environment extension, geometry-locked object removal, and style-matched batch variants.

### 3. Interactive Demo
Self-contained visual walkthroughs of novel Firefly uses.
