# Cinematic Shortcut Pack

Power-user patterns for Firefly + Photoshop.  
**Tone:** High visual standards. Firefly as part of a cinematic production pipeline.

## Core Patterns

### Environment Extension
- Select area outside the product.  
- Generative Fill with locked product reference.  
- Prompt: “matching golden hour, film grain, Kodak Ektar, light leaks, hyper-detailed environment, cinematic continuity.”  
- Verify geometry and reflections stay intact.

### Geometry-Locked Object Removal
- Precise selection around unwanted elements.  
- Generative Fill with strong product lock language.  
- Prompt reinforcement: “preserve exact product geometry, material, and lighting.”  
- Check edges and specular highlights.

### Style-Matched Batch
- Start from approved master.  
- Generate variants with shared style reference.  
- Export multi-channel set in one pass (social crops, hero, lifestyle).

## Usage Notes
These patterns assume you already work at a high level of visual control. They are not beginner tips.
