# Cinematic Shortcut Pack

Power-user patterns for Firefly + Photoshop.

## Core Shortcuts / Patterns

### Environment Extension
- Select area outside product.  
- Generative Fill with locked product reference.  
- Prompt for cinematic lighting continuity (e.g., "matching golden hour, film grain, Kodak Ektar").

### Geometry-Locked Object Removal
- Precise selection.  
- Generative Fill with strong product lock language.  
- Verify edges and reflections.

### Style-Matched Batch
- Start from approved master.  
- Generate variants with shared style seed / reference.  
- Export multi-channel set in one pass.

## Tone

These are not beginner tips. They assume high visual standards and treat Firefly as part of a cinematic production pipeline.
